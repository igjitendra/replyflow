# Phases.md

> Development roadmap — phase-wise. Har phase ka clear goal aur exit criteria hai. Ek phase complete hue bina agle par mat jao.

## Phase 0 — Planning & Foundation (2-3 din)
*Goal: Architecture lock, coding se pehle.*
- [ ] Brand Identity finalize (logo, colors, fonts)
- [ ] Information Architecture (categories, URLs, navigation)
- [ ] Content Schema finalize (frontmatter structure)
- [ ] MVP scope lock
- [ ] Sabhi docs (PRD, Architecture, Rules, Design) approve

**Exit criteria:** Saari 4 core decisions documented aur approved.

## Phase 1 — MVP Setup (Week 1)
*Goal: Chalti hui skeleton site.*
- [ ] Astro + Tailwind project setup
- [ ] Content Collections + schema validation
- [ ] Base layouts + core components (Card, CopyButton, SearchBar)
- [ ] 1 industry (Real Estate) fully seeded as pilot
- [ ] Cloudflare Pages par deploy

**Exit criteria:** Ek industry live, template copy ho raha hai.

## Phase 2 — Content Scale (Week 2-3)
*Goal: Templates aur industries badhao.*
- [ ] 5-6 core industries seed (Clinic, Salon, Restaurant, Retail, Gym)
- [ ] Multi-channel templates (WhatsApp, SMS, Email)
- [ ] Pagefind search integrate
- [ ] Metadata filters (tone, language, objective)
- [ ] Multi-language content (Hindi/English/Hinglish)

**Exit criteria:** 500+ templates, working search + filters.

## Phase 3 — UX Polish & SEO (Week 4)
*Goal: Discoverable + delightful.*
- [ ] SEO: meta, sitemap, OG images, structured data
- [ ] WhatsApp Chat Preview component
- [ ] Related templates
- [ ] Homepage: trending, recently added, popular
- [ ] Performance tuning (Lighthouse 95+)

**Exit criteria:** Organic search se traffic aana shuru.

## Phase 4 — Power Features (Month 2)
*Goal: Retention badhao.*
- [ ] Favorites / Collections (localStorage)
- [ ] AI Rewrite (user's own API key — Gemini/ChatGPT/Anthropic)
- [ ] PWA (offline)
- [ ] Edit + share flows

**Exit criteria:** Returning users + AI feature live.

## Phase 5 — Accounts & Growth (Month 3+)
*Goal: Community + scale.*
- [ ] User accounts (optional)
- [ ] Cloud-synced collections
- [ ] AI Template Generator
- [ ] Analytics dashboard
- [ ] Community-submitted templates

**Exit criteria:** 5,000+ templates, growing user base.
